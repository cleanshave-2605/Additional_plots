# Additional_plots

This repository has the additional plots for better clarity regarding the claims made in the work - ``Stay or Stray: A Dynamical Systems Viewpoint of Popularity Bias``


## Scatter_plots

This directory contains the 2-D scatter plots to display the joint trend of $(\Delta \alpha_1, \Delta \alpha_{-1})$. The plots conclusively show that the lower-left quadrant is empty, verifying Theorem 5.1 in the work. Each of the figures is labelled as ``Fig_10_<p>.pdf`` where the $p$ stands for the fraction of popular users in the system. It is also evident from the plots that as we move from ``Fig_10_0.1.pdf`` to ``Fig_10_0.9.pdf``, the variation in the x-axis ($\Delta \alpha_1$) becomes greater while the variation in the y-axis ($\Delta \alpha_{-1}$) becomes smaller.
