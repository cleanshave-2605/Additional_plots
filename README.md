# Additional_plots

This repository has the additional plots for better clarity regarding the claims made in the work - ``Stay or Stray: A Dynamical Systems Viewpoint of Popularity Bias``


## Scatter plots

This directory contains the 2-D scatter plots to display the joint trend of $(\Delta \alpha_1, \Delta \alpha_{-1})$. The plots conclusively show that the lower-left quadrant is empty, verifying Theorem 5.1 in the work.
